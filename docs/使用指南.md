## 1. 系統需求

- Android 8.0（API 26）以上。
- 可連線至任一 **OpenAI 相容** API 端點（雲端服務或自架如 Ollama / LM Studio / vLLM）。
- 一組有效的 API Key（若端點無需驗證則可留空，依服務而定）。

App **不內建任何 API Key**，所有連線資訊與金鑰僅儲存於您的裝置本機，且 API Key 以 Android Keystore 加密保存。

## 2. 安裝 App

### 取得測試版 APK

由 GitHub Release 頁面下載 `app-prerelease.apk`（Pre-release 測試版本），或自行由原始碼建置（見 [`建置與發行指南.md`](建置與發行指南.md)）。

### 側載安裝

1. 將 APK 傳至裝置（USB、雲端硬碟等）。
2. 於裝置「設定 → 安全性」允許「安裝未知的應用程式」。
3. 點擊 APK 完成安裝。

> **注意**：`app-prerelease.apk` 為以 **Debug 金鑰簽署** 的測試版，並非正式上線版本，請勿用於正式環境。

## 3. 首次設定：建立 API 設定檔

開啟 App 後，先到底部導覽的 **「API設定」** 分頁建立連線設定。

1. 點右下角 **＋** 新增設定檔。
2. 填寫欄位：

   | 欄位 | 說明 |
   | --- | --- |
   | 設定名稱 | 自訂辨識名稱，例如「本機 Ollama」。 |
   | Base URL | OpenAI 相容端點，通常以 `/v1` 結尾，例如 `https://api.deepseek.com/v1`。 |
   | API Key | 服務金鑰，可切換顯示 / 隱藏。加密儲存。 |
   | 模型名稱 | **必填**，須與端點 `/models` 回報的 id 一致。 |
   | System Prompt | 系統提示，可留空。 |
   | Temperature | 取樣溫度滑桿，範圍 0.0–2.0。 |
   | Max Output Tokens | 最大輸出 token。**0 = 不指定**，由伺服器決定；思考型模型建議留 0。 |
   | Context Window | 模型上下文長度（用於裁剪歷史）。 |
   | Thinking 模式 | DeepSeek 專用：預設（不指定）/ 啟用 / 停用。 |
   | Reasoning Effort | DeepSeek 專用：預設 / `none` / `low` / `high` / `max`。 |

3. 點 **「測試連線」**：
   - 成功後會列出可用模型 id，並提供**下拉選單**挑選模型，避免手動輸入錯誤。
   - 失敗時顯示原因（401 / 403 / 404 / 429 / 伺服器錯誤等）。
4. 儲存後，於清單以 **RadioButton** 選擇「使用中」的設定檔。

> 可建立**多組設定檔**並隨時切換；對話清單標題右側會顯示目前全域啟用的設定檔名稱。

## 4. 開始對話

1. 切換到 **「對話」** 分頁，點右下角 **＋** 新增對話。
   - 若尚未設定 API，App 會引導至設定頁。
   - 對話採**延後建立**：只有在送出第一則訊息後才寫入資料庫，未輸入就返回不會留下空白對話。
2. 在輸入框輸入問題，點送出鈕或按鍵盤 **Enter / Send** 鍵送出。
3. 回覆會以 **串流（逐字）** 方式顯示：
   - 思考型模型（DeepSeek）的 `reasoning_content` 會以淡化的「思考中…」區塊呈現。
   - 串流中送出鈕會變為**停止鈕**，可隨時中斷；已產生的內容仍會保存。
4. 回覆完成後自動寫入本機資料庫。
5. 畫面頂端會顯示 **Token 資訊列**（本次估算 token 數與被省略的早期訊息數）。

## 5. 對話管理

於「對話」清單頁：

- **新增對話**：右下角 ＋。
- **刪除對話**：點刪除圖示，確認後連帶刪除該對話所有訊息。
- **重新命名**：長按 / 點擊重新命名圖示。
- **排序**：依「最後更新時間」由新到舊。
- **搜尋標題**：清單上方搜尋欄輸入關鍵字，即時篩選符合的對話（不分大小寫、子字串比對）；按欄位右側 **x** 清除關鍵字，恢復完整清單。搜尋欄會隨清單一起捲動。
- **進入既有對話**：標題列立即顯示對話名稱，畫面頂端會停在**最後一個問題**，載入期間顯示進度指示。
- **捲動行為**：只有當您已位於底部時才跟隨串流自動捲動；向上閱讀時不被打斷，並可點右下「回到底部」按鈕。

## 6. 訊息操作

### 長按「使用者訊息」

彈出選單：

- **複製**：將問題內容複製到系統剪貼簿。
- **再次發問**：把該問題帶入輸入框，可編輯後重新送出（不自動刪除原問答）。
- **刪除**：確認後刪除該問題**及其對應的助理回答**。

### 長按「助理回覆」

彈出選單：

- **複製**：複製回覆內容。
- **朗讀**：以系統 TTS 唸出回覆（見下一節）。

> 不允許單獨刪除助理回覆，以避免問答錯位。

---

## 7. 朗讀（TTS）

- 長按助理回覆選擇 **「朗讀」**。
- 朗讀期間頂部列顯示 **播放 / 暫停** 與 **停止** 圖示；正在朗讀的氣泡以主色外框標示。
- 朗讀前會移除 Markdown 符號，但保留清單標記（如有序 `1.` / `2.`、無序 `-` / `*` / `+`）。
- 可於 **App 設定** 開啟「**總是朗讀**」，讓每次回覆完成後自動朗讀。
- 朗讀語言可選：系統預設 / 中文（台灣）/ English；若裝置不支援所選語言，會提示並改用系統預設語音。

## 8. App 設定

由**對話清單（主畫面）右上角齒輪圖示**進入「設定」頁（此頁與底部導覽的「API設定」分頁不同）。

| 設定項 | 說明 |
| --- | --- |
| 顯示模式 | 系統預設 / 淺色 / 深色，預設為**系統預設**；即時套用至整個 App（含系統列圖示配色）。 |
| 字型大小 | 滑桿調整 **12–24sp**，附即時預覽；套用至訊息氣泡（含 Markdown 標題、程式碼區塊、表格，依比例縮放）、輸入框與 Token 資訊列。 |
| 總是朗讀 | 開啟後，LLM 每次回覆完成會自動以 TTS 朗讀該回覆。 |
| 朗讀語言 | 系統預設 / 中文（台灣）/ English。 |

所有設定皆持久化（DataStore），重開 App 後保留。

## 9. 除錯記錄

App 內建除錯記錄頁，**無需連接 Logcat**。

- **進入方式**：「API設定」頁右上角蟲蟲圖示。
- **記錄內容**：送出的請求（body，**不含 API Key**）、每個原始 SSE 事件、非串流後備結果、`finish_reason`、錯誤（含伺服器回應內容）。
- **操作**：由新到舊顯示、顏色分級；「複製全部」可貼出；「清空」刪除記錄。
- **開關**：可設定「啟用記錄」開啟 / 關閉（狀態持久化）。

## 10. 大螢幕 / 平板操作

依螢幕寬度自動切換（門檻 600dp）：

- **精簡（手機）**：底部 `NavigationBar`，單頁堆疊導航。
- **展開（平板 / 大螢幕）**：左側 `NavigationRail`；對話頁為**清單 + 聊天雙欄**，直接在左欄選取對話，右欄即時顯示，不經額外轉場。

## 11. 常見問題（FAQ）

**Q：App 沒有內建模型或金鑰？**
A：是的。本 App 為純客戶端，需您自行提供 API 端點與金鑰。

**Q：可以使用本機服務嗎？**
A：可以。App 允許 cleartext HTTP，以支援自架的 Ollama / LM Studio / vLLM 等。請僅設定可信任的端點。

**Q：輸入模型名稱後測試失敗？**
A：確認模型名稱與端點 `/models` 回報一致；建議先用「測試連線」並由下拉選單挑選。

**Q：出現 400 錯誤？**
A：`thinking` 與 `reasoning_effort` 屬 DeepSeek 特有欄位，部分第三方服務不支援。請將 **Thinking 模式設為「預設（不指定）」** 後重試。

**Q：回覆沒有跑完就停止？**
A：可能達到 `Max Output Tokens`。請提高該值或縮短問題；若為思考型模型，可考慮將 Thinking 模式設為停用。

**Q：Token 數字準確嗎？**
A：為**近似值**，僅用於裁剪判斷，非精準計費依據。

**Q：`app-prerelease.apk` 可以長期使用嗎？**
A：此為以 Debug 金鑰簽署的 **Pre-release 測試版**，僅供測試，不建議用於正式環境。
